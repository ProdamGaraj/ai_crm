### 2. Исправлена авторизация в API клиенте
Проблема: файл `permissions.ts` использовал прямой `axios` вместо настроенного `apiClient` с токенами.

**Исправление:**
```typescript
// ❌ Было:
import axios from 'axios';
const response = await axios.get(`${API_BASE_URL}/api/permissions/companies/`);

// ✅ Стало:
import apiClient from './axios';
const response = await apiClient.get(`/permissions/companies/`);
```

Теперь все запросы к `/api/permissions/` автоматически включают JWT токен из Redux store.

### Назначенные разрешения

Пользователь `admin` теперь имеет:

| Параметр | Значение |
|----------|----------|
| **Роль** | Системный администратор |
| **Разрешений** | 352 из 352 (100%) |

### Что может делать администратор

С этими правами пользователь может:

✅ **Просматривать** все ресурсы (VIEW_*_SYSTEM)
✅ **Создавать** любые объекты (ADD_*_SYSTEM)
✅ **Редактировать** любые объекты (EDIT_*_SYSTEM)
✅ **Удалять** любые объекты (DELETE_*_SYSTEM)

Включая:
- Клиентов, заявки, встречи
- Сделки, платежи, возвраты
- Проекты, здания, объекты недвижимости
- Скидки, документы, отчеты
- Компании, отделы, роли, пользователей

## 🔄 Настройка для других пользователей

### Создать администратора для другого пользователя

```bash
python manage.py setup_admin_permissions --username <username>
```

Пример:
```bash
python manage.py setup_admin_permissions --username manager1
```

### Создать пользователя с ограниченными правами

1. В Django Admin создайте UserProfile
2. Выберите компанию и отдел
3. Назначьте подходящую роль:
   - **Администратор компании** - управление компанией
   - **Руководитель отдела** - управление отделом
   - **Менеджер** - работа со своими объектами
   - **Наблюдатель** - только просмотр

## 🐛 Troubleshooting

### Проблема: Всё еще ошибка 401

**Решение 1:** Перелогиньтесь
1. Выйдите из системы (Logout)
2. Войдите снова с новыми правами

**Решение 2:** Очистите localStorage
```javascript
// В консоли браузера (F12)
localStorage.clear();
```
Затем перезагрузите страницу и войдите снова.

**Решение 3:** Проверьте токен
```javascript
// В консоли браузера
const state = JSON.parse(localStorage.getItem('persist:root'));
console.log('Token:', JSON.parse(state.auth).accessToken);
```
Если токен пустой - перелогиньтесь.

### Проблема: Нет профиля пользователя

```bash
# Запустите команду еще раз
python manage.py setup_admin_permissions --username admin
```

### Проблема: Не все разрешения

```bash
# Переинициализируйте разрешения
python manage.py init_permissions
# Затем заново настройте администратора
python manage.py setup_admin_permissions --username admin
```
