```typescript
... и т.д.
```

**Применено в:**

### 3. ✅ Загрузка отделов при инициализации

**Проблема:** Отделы не загружались при первом открытии страницы, но появлялись после добавления нового отдела.

**Причина:** В `useQuery` был некорректный `enabled` condition:
```typescript
enabled: !!selectedCompany || selectedCompany === ''
```
Это условие всегда было `true`, но блокировало загрузку из-за логической ошибки.

**Решение:**
Убрал `enabled` condition полностью:
```typescript
const { data: departments, isLoading, isError, error } = useQuery({
  queryKey: ['departments', selectedCompany],
  queryFn: () =>
    getDepartments(selectedCompany ? { company: Number(selectedCompany) } : {}),
  // enabled убран - запрос выполняется всегда
});
```

**Теперь работает:**
- ✅ Отделы загружаются сразу при открытии страницы
- ✅ Фильтрация по компании работает корректно
- ✅ При перезагрузке страницы отделы не пропадают

## 🧪 Как проверить

### 1. Проверьте роутинг ролей

```
http://localhost:5174/settings?tab=roles
```

**Действия:**
1. Кликните на название любой роли (например, "Системный администратор")
2. Должна открыться детальная страница с матрицей разрешений
3. URL должен быть: `/permissions/roles/1`

### 2. Проверьте переводы

На детальной странице роли проверьте:

**Действия (Action):**
- ✅ "Просмотр" вместо VIEW
- ✅ "Создание" вместо ADD
- ✅ "Редактирование" вместо EDIT
- ✅ "Удаление" вместо DELETE

**Области (Scope):**
- ✅ "Свои" вместо OWN
- ✅ "Отдел" вместо DEPARTMENT
- ✅ "Компания" вместо COMPANY
- ✅ "Система" вместо SYSTEM

**При создании новой роли:**
1. Нажмите "Создать роль"
2. Раскройте accordion "Клиенты"
3. Проверьте, что разрешения отображаются как:
   - "Просмотр" + чип "Свои"
   - "Создание" + чип "Отдел"
   - и т.д.

### 3. Проверьте загрузку отделов

```
http://localhost:5174/settings?tab=departments
```

**Действия:**
1. Откройте вкладку "Отделы"
2. **Сразу** должны отобразиться все отделы в древовидной структуре
3. Выберите компанию в фильтре → должны отобразиться отделы этой компании
4. Нажмите F5 (перезагрузить страницу)
5. Отделы должны снова загрузиться автоматически
