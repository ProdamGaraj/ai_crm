## 🧪 Как проверить

### 1. Откройте страницу настроек
```
http://localhost:5174/settings
```

### 2. Перейдите на вкладку "Роли"
```
http://localhost:5174/settings?tab=roles
```

**Проверьте:**
- ✅ Отображается таблица с системными ролями
- ✅ Видны роли: Системный администратор, Администратор компании, Руководитель отдела, Менеджер, Наблюдатель
- ✅ Для каждой роли указано количество разрешений
- ✅ Кнопка "Создать роль" открывает форму

**Создайте новую роль:**
1. Нажмите "Создать роль"
2. Заполните:
   - Название: "Тестовая роль"
   - Код: "TEST_ROLE"
   - Уровень: Отдел
   - Описание: "Для тестирования"
3. Раскройте accordion "Клиенты"
4. Выберите несколько разрешений
5. Нажмите "Создать"
6. Роль должна появиться в таблице

### 3. Перейдите на вкладку "Пользователи"
```
http://localhost:5174/settings?tab=users
```

**Проверьте:**
- ✅ Отображается таблица пользователей
- ✅ Виден пользователь `admin` с индикатором "Системный админ: Да"
- ✅ Работают фильтры по компании, отделу, статусу
- ✅ У `admin` должна быть роль "Системный администратор"

**Отредактируйте пользователя:**
1. Кликните на строку с пользователем `admin`
2. Откроется форма редактирования
3. Измените:
   - Должность: "Главный администратор"
   - Телефон: "+7 (999) 123-45-67"
4. Добавьте ещё одну роль (если создали тестовую)
5. Нажмите "Сохранить"
6. Изменения должны отобразиться в таблице

### 4. Фильтрация пользователей

**Проверьте фильтры:**
1. В фильтре "Компания" выберите "Системная компания"
   - Должны отобразиться только пользователи этой компании
2. В фильтре "Отдел" выберите "Администрация"
   - Должны отобразиться только пользователи этого отдела
3. В фильтре "Статус" выберите "Активные"
   - Должны отобразиться только активные пользователи
